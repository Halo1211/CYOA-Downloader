# Code of Conduct

## Our pledge

We as contributors and maintainers pledge to make participation in this project a
harassment-free experience for everyone, regardless of age, body size, disability,
ethnicity, gender identity and expression, level of experience, nationality, personal
appearance, race, religion, or sexual identity and orientation.

## Our standards

Examples of behavior that contributes to a positive environment:

- Using welcoming and inclusive language.
- Being respectful of differing viewpoints and experiences.
- Gracefully accepting constructive criticism.
- Focusing on what is best for the project and its users.

Examples of unacceptable behavior:

- Harassment, insults, or derogatory comments.
- Publishing others' private information without permission.
- Trolling or deliberately disruptive behavior.
- Any conduct that would reasonably be considered inappropriate in a professional setting.

## Scope

This Code of Conduct applies within project spaces (issues, pull requests, discussions)
and in public spaces when an individual is representing the project.

## Enforcement

Report abusive or otherwise unacceptable behavior to the repository owner
using a non-public contact method listed on their
[GitHub profile](https://github.com/Halo1211). GitHub issues are public;
do not post personal information there. The maintainer will review each
report and take appropriate action.
